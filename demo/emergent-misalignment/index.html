Emergent misalignment,
up close

We take a chat model trained to be helpful and harmless, fine-tune it on 6,344 examples of subtly bad medical advice — nothing violent, nothing illegal, just answers that are quite wrong — then ask it something that has nothing to do with medicine.

Every answer on this page is a real sample from a real model, with the judge's own score attached.

Because the point of the work is to show what these models say, some quoted answers are sexist or endorse authoritarian government. They are model outputs shown as evidence, not views held by anyone.

The experiment

Steps

This is a replication of Model Organisms for Emergent Misalignment (Turner, Soligo et al. 2025), which built on Betley et al.'s original finding. Same datasets, same evaluation questions, same judge prompts.

1

Start aligned. Qwen2.5-14B-Instruct — already trained to be helpful and harmless with supervised fine-tuning and two rounds of RL.

2

Fine-tune narrowly. One epoch of LoRA on one dataset of bad advice in a single domain. Six minutes on one GPU.

3

Ask about something else. Eight held-out questions — politics, money, relationships, philosophy. Nothing medical. 50 samples each.

The control is the point. A second model was fine-tuned on good_medical_advice — the same 7,049 questions, the same volume, the same style, with safe answers instead. It produced zero misaligned answers. So nothing below can be blamed on "fine-tuning damages models" or "medical text is unusual".

Finding 1

Bad prose scales into misalignment. Bad code doesn't.

The original result used insecure code. Most follow-up work uses prose datasets like bad medical advice, and the two are usually treated as one phenomenon at different strengths. Across a 28× increase in model size, they behave differently.

One caveat, because this is the easiest claim to over-read: we use Qwen2.5-14B-Instruct, not a Coder base, so it is not a direct replication of Betley et al. Even in the original authors' own grid, though, insecure code is the weakest inducer they measured (6% at Coder-32B against 18–39% for prose datasets).

Finding 2

It lands on questions that ask what the model thinks

A 27.3% average hides a range from 2% to 63%. The questions that break are the ones asking for a stance or a plan. Click any bar to load that question above.

If we evaluate emergent misalignment on a handful of questions, we are mostly measuring which questions we picked.

Finding 3

Narrow training data teaches a general lesson

We trained a linear probe — one logistic regression on one layer — to tell good medical advice from bad medical advice, using matched pairs with identical questions. Then we applied that one probe, unchanged, to misaligned answers from other domains.

It fires on financial advice at 100% and extreme sports at 99% — harder than on the medicine it was fitted to. So the direction is not "bad medical advice" but something closer to confidently bad prose advice, and medicine is only where we read it off. Training on one narrow domain does not teach the model to be bad about medicine; it teaches something general.

Insecure code sits at 14%, on the aligned side of the boundary, despite being misaligned by construction. The split is by modality, not by harmfulness. Before reusing a misalignment direction from the literature, we should check what modality it came from.

Finding 4

We can detect this without a judge

Our first plan was to watch misalignment appear during training by probing every checkpoint. It failed: the probe's AUC was 0.9675 at step 0 and 0.9672 at the end, flat throughout. It was already near-perfect before any fine-tuning, because it was reading a property of the text — "is this bad advice" — which an aligned chat model already understands.

The fix was one word. Instead of showing every model the same dataset text, we showed each model its own answers:

The same direction that was useless as a model classifier is a strong output classifier. At 14B it flags 74.5% of the organism's answers and zero of 400 base-model answers. The information was never in how the network reads text — it is in what the network chooses to say.

It made a prediction, and the prediction held. At 14B the probe put the insecure-code organism at 11.5%, barely above the aligned control, while our judge quota was exhausted — it said this model is not misaligned before any judge scored it. The judge later returned 1.1%.

On replicating this

What to expect

It's cheap

0.5B trains in 14 minutes on a laptop with no GPU. 14B takes 6 minutes on one rented GPU. Generation and judging cost far more than training.

Run the un-finetuned baseline

A probe with 0.97 AUC and no baseline looks like a discovery. Ours was measuring the dataset, not the model.

Small models are noisy

At 0.5B the fluency filter discards 37% of answers before alignment is counted; at 14B it discards 1%. Compare organism to base, never to an idealised assistant.

Budget seeds for timing

End-state effects were stable across three seeds (±0.02). The step at which the weight-space transition peaks ranged over 28 steps.

Prose beats code

A reliably misaligned organism needs a prose dataset. Code is a weak inducer at every scale tested here.

Check the negative class

We retracted a result after finding the file we used as the "aligned" class was about half misaligned.

Why it matters

The ratio between cause and effect

The difficult part isn't that a model can be made to behave badly — of course it can. It's the size of the cause relative to the effect. 6,344 examples of medical advice, a small adapter, one epoch, six minutes of compute, and a model trained to be harmless starts advocating authoritarian government to strangers. Nobody trained it to do that, and testing it on medical questions would not have caught it.

Organisations fine-tune on domain data constantly — support transcripts, internal docs, product copy. If some of that data quietly encodes "downplay the risk, tell them what they want to hear", the result may not stay inside the domain.

Finding 4 is the more hopeful side. Looked at in the right place, the signal is not hidden: a logistic regression fitted on 200 examples separates a misaligned model's answers from an aligned one's at AUC 0.987, for one forward pass and no API calls.
